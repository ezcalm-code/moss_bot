# Roadmap

分期规划与验收标准（AC 逐条编号；「没有用例的标准视为未验收」）。实现进度勾选在本文件与 `docs/tasks/todo.md` 同步维护。

## v0.1 聊天版（第一期）

范围：Telegram + 飞书双平台、OpenAI 兼容多模型可插拔、聊天（多轮上下文 / 流式回复 / 人设）、基础命令、会话存储（memory / file）、Docker 部署。

## v0.2 多模态与体验

- 图片理解（attachments 已预留类型形状）
- Markdown 渲染回复（平台方言适配）
- per-user 群聊模型覆盖、管理员/权限体系
- token 用量统计、对话导出
- better-sqlite3 存储（SessionStore 接口已预留）
- i18n 文案抽取

## v0.3 任务执行（对标 grok bot 的「干活」能力）

- tool use / agent loop：`LLMProvider` 与 `BotCore` 管道已预留扩展点（消息结构、命令路由）
- 平台侧扩展点：`attachments` 类型、命令注册表
- 具体能力清单届时另行规划（如：搜索、定时任务、文档处理）

## 非目标（v0.1 明确不做）

插件系统、多 bot 实例、webhook 部署模式、任何数据库/ORM、图片语音文件理解、卡片按钮交互、Markdown 渲染、prompt 缓存、限流精细治理（grammY throttler 兜底即可）。
