## REPL 实测（2026-11-09）

| 场景 | 结果 |
|---|---|
| 自然语言「90秒后提醒我起来活动一下」 | PASS：模型按注入的时钟算出绝对时间→工具设置→90 秒后终端收到「⏰ 提醒（来自 User）…」 |
| 命令 /remind → /reminders → /unremind（无 id 拒绝）→ /reminders | PASS 全链路 |
| 重启补投 | PASS：过期后重启，输出「⏰ [过期提醒 · 原定 …]」前缀 + pino「提醒到期投递」留痕，盘清零 |
| 修复过程发现 | REPL 退出被 pino-pretty worker 挂住进程（exitCode 软退出永不生效、stdout 回调式退出在 /dev/null 下不触发），改用普通 timer 硬退；进程曾存活至到期把提醒投进 /dev/null——正是当初「补投无打印」假象的根源 |
